Program Flow Chart
=================

main
 |
 +---> parse_args
       |
       +---> [Invalid] ---> Print Usage ---> End
       |
       +---> [Valid] ---> init_simulation
                           |
                           +---> init_mutexes
                                 |
                                 +---> [Success] ---> init_philos
                                 |                    |
                                 |                    +---> [Success] ---> run_simulation
                                 |                    |                    |
                                 |                    |                    +---> get_time
                                 |                    |                    |
                                 |                    |                    +---> Create Philosopher Threads
                                 |                    |                    |      |
                                 |                    |                    |      +---> philo_routine
                                 |                    |                    |             |
                                 |                    |                    |             +---> get_sim_state
                                 |                    |                    |             +---> take_forks
                                 |                    |                    |             +---> philo_eat
                                 |                    |                    |             +---> release_forks
                                 |                    |                    |             +---> philo_sleep_think
                                 |                    |                    |             +---> [Loop until stopped]
                                 |                    |                    |
                                 |                    |                    +---> Create Monitor Thread
                                 |                    |                    |      |
                                 |                    |                    |      +---> monitor_routine
                                 |                    |                    |             |
                                 |                    |                    |             +---> check_death
                                 |                    |                    |             +---> check_meals_complete
                                 |                    |                    |             +---> [Loop until stopped]
                                 |                    |                    |
                                 |                    |                    +---> Wait for Threads
                                 |                    |                    +---> cleanup_simulation
                                 |                    |                    +---> End
                                 |                    |
                                 |                    +---> [Fail] ---> Cleanup & Return Error
                                 |
                                 +---> [Fail] ---> Cleanup & Return Error
